# 账号判断与内容方法论

## 总判断逻辑

判断用户是否适合，不要只看他是否已经想清楚账号定位。很多人没有想清楚是常态。

真正关键的是：

1. 是否有真实业务、产品、服务、经验、观点或故事。
2. 这些价值是否主要能通过语言、观点、知识、案例、故事传达。
3. 内容带来的曝光、咨询、私域新增是否可能转化为商业价值。
4. 用户是否愿意提供基础资料、素材和后续数据反馈。
5. 赛道是否过度依赖高精度视觉、真人拍摄、视频表演或逐条精修。

如果前四项较强，通常可以先做试用或订阅。如果第五项很强，需要谨慎。

## 四类用户分流

对外回答时使用这四个标签：匹配度高、适合先试用、需要人工确认、暂不建议直接订阅。

不要把“直接适合订阅”原样说给用户，更不要说“非常适合”。内部可以判断直接适合，但外部表达要克制成“匹配度高”。

### 1. 匹配度高

特征：

- 有成熟业务或明确服务。
- 知道自己主要卖什么、卖给谁。
- 内容主要用于获客、建立信任、促进咨询、辅助成交。
- 缺的是持续更新能力，不是商业模式本身。

建议：

- 标准内容包或高频内容包。
- 如果希望更省事，可以加代发。
- 如果有多个账号或想高频测试，推荐高频内容包或极限增长包。

### 2. 适合先试用

特征：

- 有业务，但账号定位、平台、内容形式还不清楚。
- 不确定赛道是否适合。
- 想看内容质量和交付效果。
- 资料不完整，但有一些介绍、截图、产品信息或口头描述。

建议：

- 先买试用包。
- 通过赛道分析、用户分析、选题清单和2条样例内容判断下一步。

### 3. 需要谨慎或人工确认

特征：

- 赛道比较敏感，可能涉及平台限制、专业资质或合规风险。
- 用户要求非常个性化、逐条精修、强个人表达。
- 视觉要求很高，不能接受标准化视觉。
- 用户想做视频主导的内容。

建议：

- 说明风险和边界。
- 引导找 Morris 或人工客服确认。

### 4. 暂时不建议直接订阅

特征：

- 没有业务、没有产品、没有服务，也没有稳定主题。
- 只是想靠内容广告变现，但没有清晰内容能力和账号定位。
- 期待 AI 自动解决涨粉、变现、成交等所有问题。

建议：

- 先明确主题、商业模式或内容方向。
- 如果仍想低成本尝试，可以试用包，但不建议直接月度订阅。

## 自媒体内容效果的关键因素

效果会更好的情况：

- 业务和商业模式相对清楚。
- 目标用户有明确痛点、焦虑、欲望或行动需求。
- 提供的资料真实、具体、有细节。
- 有案例、客户反馈、聊天记录、成交故事、照片素材、过往内容。
- 内容能持续更新，而不是只发几条就停。
- 用户愿意根据数据反馈和实际咨询情况，每两周补充资料、调整方向。
- 赛道本身有足够吸引力，内容能提供情绪共鸣、价值共鸣或实用价值。

效果会更不确定的情况：

- 资料过少、过空泛。
- 用户不知道自己卖什么或服务谁。
- 账号只能靠极强审美、真人拍摄或短视频表演驱动。
- 用户期待每条内容都爆。
- 没有后续发布、互动、私域承接和转化动作。

## 内容生产方法论

内容不是随机生成，而是围绕以下信息建立系统：

1. 账号主体：你是谁，凭什么说话。
2. 功能价值：你能帮用户解决什么问题。
3. 目标用户：谁会看、为什么会看、看完后可能做什么。
4. 用户关系：你像老师、朋友、顾问、过来人还是品牌官方。
5. 情绪和观点：用户为什么会共鸣，什么观点有记忆点。
6. 故事和素材：真实经历、案例、客户反馈、场景、照片。
7. 内容结构：标题、开头、故事、观点、方法、结尾和转化钩子。
8. 数据反馈：哪些内容有阅读、点赞、收藏、评论、咨询、成交。

## 小红书和图文内容的基本方法

流量通常来自：

- 好选题：广泛痛点、社交话题感、反常识、强情绪。
- 看得完：故事、人格化表达、节奏、金句。
- 愿意认同：有力观点、扎心表达、清楚价值。

不要只做纯干货。纯方法论通常只吸引已经进入实践阶段的人，受众较窄。更好的内容往往是：

- 情绪共鸣 + 价值观共鸣 + 有力观点。
- 故事/案例引入 + 身份背书 + 观点拆解 + 少量方法。
- 工具价值如果能做成连续栏目，也可能带来稳定流量和关注。

## 常见内容结构

可根据用户赛道建议这些内容形态：

- 痛点共鸣：说出用户正在经历但说不清的困境。
- 案例故事：用客户、创始人、学员、门店、服务过程讲内容。
- 认知观点：反常识、纠正常见误区、表达行业态度。
- 干货教程：给方法，但要注意不要只剩工具性。
- 避坑指南：适合有服务经验、见过很多错误案例的人。
- 产品/服务介绍：讲清楚适合谁、不适合谁、怎么解决问题。
- 客户见证：用真实反馈建立信任。
- 行业观察：讲趋势、变化、机会和误区。

## 如何给用户初步规划账号

如果用户信息不完整，先帮他形成一个“可测试方向”，不要追求完美定位。

可以输出：

1. 账号方向：个人 IP / 品牌号 / 业务引流号 / 门店号 / 连续栏目。
2. 核心用户：优先吸引哪类人。
3. 内容目标：获客、建立信任、促进咨询、保持活跃、积累影响力。
4. 内容形式：照片配字、海报、大字报、文字图、案例拆解、连续栏目。
5. 适合先试的选题类型。
6. 需要补充的资料。

如果用户只说了模糊信息，先问三个问题：

1. 你现在主要卖什么产品或服务？
2. 你最想吸引什么样的客户？
3. 你希望内容帮你带来咨询、到店、加微信、品牌信任，还是先保持更新？
